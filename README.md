# Quantum Entanglement

**Status:** original browser puzzle game  
**Play:** https://joenasriani.github.io/quantum-entanglement-game/  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Quantum Entanglement is a dual-control browser puzzle game where one input moves two linked particles and level geometry affects each particle differently.

## Gameplay

Guide the Cyan and Magenta particles to their matching target zones. Standard walls block both particles, while color-specific phase walls block only one. Once a particle reaches its goal it can lock in place while the remaining particle is solved.

The game contains forty progressive levels and supports keyboard and touch controls.

## Scope

The title and mechanics are inspired by the idea of linked particles. This is a **puzzle game**, not a scientific quantum-mechanics simulator and not a quantum-computing implementation.

## Technology

HTML5 Canvas, JavaScript, Web Audio, Tailwind CSS and local browser storage.

Historical labels such as **Quantum Polished** refer to this same game lineage.
